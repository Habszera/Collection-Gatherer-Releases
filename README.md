# Collection Gatherer

**O livro de registros da sua coleção de Magic: The Gathering.**

Collection Gatherer é um aplicativo gratuito para Windows que cataloga cartas de Magic. Para registrar uma carta, basta digitar o código da coleção e o número de coletor impressos nela. O app busca o resto no [Scryfall](https://scryfall.com): nome, tipo, raridade e imagem. Para cada carta você anota estado, acabamento (foil), variação e idioma, e no final salva o livro ou exporta para outros sites.

Este repositório guarda só os instaladores.

## Como instalar

1. Abra a [**última versão**](https://github.com/Habszera/Collection-Gatherer-Releases/releases/latest) e baixe o arquivo **`CollectionGatherer-win-Setup.exe`**, em *Assets*.
2. Dê dois cliques no arquivo baixado. A instalação é automática: não pede senha de administrador, cria atalhos na área de trabalho e no menu Iniciar e já abre o app.

Requisitos: Windows 10 ou 11 (64 bits) e internet para consultar as cartas. Não é preciso instalar mais nada.

### "O Windows protegeu o computador"

Na primeira vez, o Windows pode mostrar uma tela azul com esse aviso. Isso acontece com programas gratuitos que não têm assinatura digital paga, e não quer dizer que o arquivo tenha vírus. Para continuar, clique em **Mais informações** e depois em **Executar assim mesmo**.

### Atualizações

O app se atualiza sozinho. Ao abrir, ele procura uma versão nova e, se houver, baixa em segundo plano. Quando termina, pergunta se você quer reiniciar para atualizar. Se você preferir continuar, a atualização é instalada na próxima vez que abrir o app.

### Desinstalar

Em *Configurações → Aplicativos → Aplicativos instalados*, procure **Collection Gatherer** e clique em *Desinstalar*. Os livros (`.cgcol`) que você salvou continuam onde você os guardou.

## Créditos

- Dados e imagens das cartas: [Scryfall](https://scryfall.com).
- Magic: The Gathering é marca registrada da Wizards of the Coast. Este é um projeto de fã, sem vínculo nem endosso da Wizards of the Coast ou do Scryfall.
